### E-20
**Ruling:** Both auditors say replace; the second opinion's widening is right and the first audit's rethrow-only correction is not sufficient. The poison design is complete as both auditors found (every statement path guarded, both shapes end in `TransactionAborted` with no rows, the mark cleared only at depth 0 — T-3-5i2 pins the recovery). The remaining catch-and-continue is the depth-0 `ROLLBACK` swallow, and its consequence is worse than "a misleading error one call later": when `ROLLBACK` fails while `db.isTransaction` is true, the frame has already set `depth = 0` with the engine still inside the transaction, so every later statement run outside `transaction()` joins that orphaned transaction — invisible to other connections and discarded at `close` — and the next `transaction()` fails with "cannot start a transaction within a transaction". Re-executed by simulation (the `ROLLBACK` line made to throw; a simulation, not a reachability proof): an autocommit-style insert of 7 "returned", a second connection saw `[]`, the next unit threw, and after `close` the table was empty, where the real code gives `[7]`, "next unit committed", `[7,8]`. Then the first audit's correction was applied on top of the same simulation — throw with the original error as `cause` instead of swallowing — and the loss is unchanged: the unit's caller sees "rollback failed" once, but the insert of 7 still returns, the other connection still sees `[]`, and after `close` the table is still empty. Surfacing the failure once does not take the handle out of a state whose transaction boundary can no longer be trusted. Fail-fast (Shore; Hunt & Thomas's "Crash Early") means the handle must refuse every later call, or be closed, after a failed `ROLLBACK`. SQLite documents `ROLLBACK` failing after an automatic rollback, which the guard excludes, so the branch is improbable; it is not shown impossible (an I/O error during the rollback is one route), and the cost of the correct form is a flag. The comment's error list is E-13's misquote, propagated, and still at HEAD.
**Evidence:**

### E-6

The first audit checked that an agent id containing `#` stays a subagent (the first-`#` rule) but not the mirror premise the rule depends on: a session id must not contain `#`. Neither the plan's Step 6 sentence, the module header nor the code states or checks it. Re-executed on both trees: the main agent of session `a#sub:b` and the subagent `b#main` of session `a` produce the identical key `a#sub:b#main`, and `consumerRole` reads the main agent as `subagent`. Two consumers sharing one key is the exact cross-consumer class (G23) the key was introduced to close; a main agent read as a subagent is silently outside FR-O6's main-only deny, the mirror of the "never silently reads as main" property the file claims. The hooks reference documents `session_id` only by example (`"abc123"`), so the premise is observed practice, not a documented contract, and reachability is low (the host issues the id) — but the key is not injective as built, and the brief's test asks for the premise to be written down and checkable.
